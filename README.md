# Saranya P Portfolio
Premium responsive portfolio for an aspiring Data Analyst.

## Run
Open the folder in VS Code and open `index.html` with Live Server, or double-click `index.html`.

## Files
- index.html
- css/style.css
- js/script.js
- assets/resume.pdf (add your real PDF here)

The analytics panel uses clearly labelled sample/demo data. No professional experience or fake project URLs are claimed.

## GitHub Pages
Upload the project to a GitHub repository, then Settings → Pages → deploy from the main branch/root.
